# 🎵 Chordly (コードリー) — AI駆動型コード進行アシスタント

> **ソフトウェア工学 期末課題7：AI駆動開発によるWebアプリケーション**  
> AIエージェントとの対話型開発（Agentic Coding）によって構築された、直感的なコード進行自動生成・編集Webアプリケーションです。

---

## 📖 1. システム概要
**Chordly** は、音楽理論に基づいた本格的なコード進行の作成・編集・エクスポートを、ブラウザ上で直感的に行えるWebアプリケーションです。  
「切なく」「明るく」「おしゃれに」といった曲の雰囲気（Mood）を選ぶだけで、王道進行・丸サ進行・カノン進行・小室進行などの名曲パターンを自動生成・提案します。

---

## ✨ 2. 主な機能

### 🎼 Mood（雰囲気）主導のコード進行自動生成
- **10種類の雰囲気（Mood）**: 💧 切なく, ✨ おしゃれに, ☀️ 明るく, 🌙 暗く, 🌸 きれいに, 🔥 力強く, 🍃 穏やかに, 💜 エモく, 🎵 ポップに, 🎬 ドラマチックに
- **キー・テンポ自動連動**: 雰囲気を選ぶだけで、そのジャンルに最適なBPMやキー・モード（Major/Minor）を自動判定。

### 🎹 リアルタイム音色プレビュー & 演奏コントロール
- **Tone.js（Web Audio API）による即時演奏**: コードブロックをクリック・ホバーするだけでリアルタイムに和音を試聴。
- **再生/停止 & メトロノーム**: トランスポートバーからいつでも全曲演奏の再生・停止が可能。

### 💡 単音＆範囲選択（Shift+クリック）置換機能
- **単音置換**: コードブロック選択時、音楽理論的に接続がスムーズな代理コード候補を提示。
- **範囲選択フレーズ置換**: Shift+クリックで複数小節（2〜4小節）を選択すると、「王道進行 (エモさ定番)」「丸サ進行 (CityPop)」「小室進行」「カノン進行」などの有名名曲フレーズパターンを一発で適用。

### 📄 高品質 MusicXML & MIDI エクスポート
- **MuseScore 連携に最適化**:
  - ト音記号（Treble Clef / 𝄞）および適切な調号（Key Signature）を自動出力。
  - 異名同音（例: Eメジャーキーでの D# / Eb のミスマッチ）を補正し、不要なナチュラル（♮）や臨時記号がつかないすっきりした楽譜を出力。
- **DAW連携**: 標準 MIDI (.mid) ファイルのエクスポートに対応。

## 🚀 3. Dockerコンテナでの起動方法

本アプリケーションは Docker コンテナ上で動作するように構成されています。

### 動作要件
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) または Docker Engine + Docker Compose

### 起動手順

1. **リポジトリのクローン**
   ```bash
   git clone https://github.com/Jam-TechLab/chordly.git
   cd chordly
   ```

2. **Dockerコンテナのビルド & 起動**
   ```bash
   docker-compose up --build
   ```

3. **ブラウザでアクセス**
   ブラウザを起動し、以下のURLを開きます。
   ```text
   http://localhost:5000
   ```

4. **コンテナの停止**
   ```bash
   docker-compose down
   ```

## 🛠️ 4. 開発プロセス & 技術スタック

### 技術スタック
- **フロントエンド**: HTML5, Vanilla CSS (Glassmorphism design), JavaScript (ES6+), Tone.js
- **バックエンド**: Python 3.11, Flask
- **音楽理論処理**: `music21`, `midiutil`
- **コンテナ化**: Docker, Docker Compose

### AI駆動開発（Agentic Coding）について
本プロジェクトは、AIエージェント（Google Antigravity / Gemini 3.6 & Claude 4.6）との対話型ペアプログラミングにより開発されました。
- **要件定義〜UI設計〜実装**: 音声再生、リアルタイム編集UI、音楽理論アルゴリズムの構築。
- **高度なデバッグ**: MuseScoreにおける MusicXML 臨時記号除去の根本原因特定と `music21` ピッチ補正ロジックの実装。
